# NEXUS OS — Settings & Control Center

وحدة مستقلة مبنية بـ React + TypeScript + Vite. لا تعتمد على ملفات NEXUS OS أو تسجيل الدخول أو قاعدة بيانات رئيسية.

## التشغيل

المتطلبات: Node.js 20+ و npm.

```bash
npm install
npm run dev
```

افتح عنوان Vite الظاهر في الطرفية. لبناء نسخة الإنتاج:

```bash
npm run build
npm run preview
```

## المزايا المنفذة

- لوحة Control Center مع مؤشرات الحساب والأمان والتخزين والمزامنة والأجهزة والنسخ الاحتياطي.
- الوحدات الخمس عشرة: الحساب، المظهر، اللغة والمنطقة، التنقل، الإشعارات، الخصوصية والأمان، الأجهزة، الحسابات المرتبطة، المستخدمون والصلاحيات، الذكاء الاصطناعي، التخزين، النسخ الاحتياطي، التكاملات، الأداء، حول التطبيق والدعم.
- بحث في إعدادات الوحدات، التنقل، حفظ التغييرات، استعادة الافتراضي، رسائل الحالة، تأكيدات الإجراءات الحساسة.
- إعدادات محلية تحفظ في `localStorage` تحت المفتاح `nexus-control-center:v1`.
- العربية والإنجليزية، RTL/LTR، الوضع الداكن والفاتح، واجهة متجاوبة.
- بيانات تجريبية واضحة ويمكن تعديلها.

## ملاحظات مهمة

الربط الخارجي، OAuth، إدارة كلمات المرور، المصادقة الثنائية الفعلية، إرسال الدعوات، إدارة الأسرار، النسخ السحابي، استعادة النسخ من خادم، وإدارة جلسات حقيقية غير متصلة. توجد واجهات محاكاة ونقاط تكامل موضحة داخل المشروع. لا تُدخل أسرار API في الواجهة الأمامية.
